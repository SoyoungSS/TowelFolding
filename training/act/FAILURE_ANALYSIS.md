# 首次ACT闭环失败分析

2026-11-10，只读分析既有200次更新的checkpoint与首次30秒闭环，没有额外训练或改变控制参数。

## 结论

本次证据首先指向**当前模型尚未充分拟合专家动作精度，以及独立运行时未能推进到抓取状态**。单条episode覆盖面不足，会限制纠偏和泛化，但不能把这次固定初态失败简单解释成“episode数量太少”。

“闭环没有闭合夹爪”也不等于“网络完全没学会闭合”：在全部815帧原始专家观测上的只读推理显示，模型在337个应闭合的帧上全部达到闭合阈值；独立运行时却一直停在更早的状态。

## 新增只读检查

输出：`outputs/act_rollout/20261110_174441_98496/diagnosis/`。

- `analysis.json`：全部815帧的离线推理统计、首帧对比、闭环最近专家关节状态。
- `offline_predictions.npz`：815帧预测第一步、专家目标和专家实际状态，均按训练规范顺序。
- `diagnose_towel_act.py`：该次诊断脚本；末尾补充的首闭合时间与精度统计来自同一NPZ。

全815帧动作块的归一化L1为0.1824。它是全训练episode上的加权平均，不是独立验证指标，也不同于第一阶段8个固定片段的平均L1 0.2552，二者不能直接当作不同模型的改进比较。

## 证据一：训练很短，动作精度仍不足

200次更新、batch 2，相当于400个图像观测起始样本，约为815帧的0.49轮。每个起点监督30步动作块；因此400不是动作标签总量，也不是400个episode。该训练只负责验证读取、更新、保存和重载，尚无收敛证据。

全训练episode第一步的14个臂关节平均绝对目标误差为0.0931 rad，约5.33度。

初始帧更差：平均关节误差0.4603 rad（约26.37度），最大单关节误差1.5295 rad（约87.63度）。专家初始帧本应保持home，模型已经给出明显偏离的目标。仿真限速可以减慢错误运动，不能使错误目标变正确。

抓取前第200–274帧：

| 量 | 平均绝对幅度 |
|---|---:|
| 模型预测与专家目标的关节差 | 0.0563 rad |
| 专家目标与当前实际关节的差 | 0.00201 rad |

前者约为后者28倍。两种误差定义不同，这个比例用于说明动作精度相对于专家细小推进量的尺度，不是一个通用任务通过阈值。视觉上动作大致接近，并不保证能持续推进到毫米尺度的抓取区域。

## 证据二：离线能识别闭合，独立运行未到达对应状态

| 指标 | 左夹爪 | 右夹爪 |
|---|---:|---:|
| 专家闭合帧数 | 337 | 337 |
| 应闭合帧的预测召回率 | 100% | 100% |
| 专家闭合时预测均值 | 0.976 | 0.996 |
| 专家打开时误判闭合帧数 | 23 | 21 |
| 首次预测闭合帧 | 262 | 266 |
| 专家首次闭合帧 | 275 | 275 |
| 闭环30秒中闭合指令数 | 0 | 0 |

这说明闭合阶段的观测与动作已有一定关联，但时机并不精确，也不代表抓取正确。该检查的全部帧仍来自同一训练episode。

按14维实际臂关节状态寻找最近的专家状态，闭环5秒最接近专家第208帧（6.93秒），10秒最接近第209帧，20秒最接近第211帧，30秒最接近第212帧。专家首次闭合为第275帧（9.17秒）。

这只是关节状态相似性诊断，不代表两者TCP、图像或毛巾状态完全一致；但它支持“模型在抓取前附近停滞”的解释。独立运行的实际观测由先前预测动作产生，专家视频里的后续观测不会自动出现。偏差与停滞会影响后续预测，形成闭环问题。

## 证据三：目前未发现明显的输入输出接线错误

- 专家与闭环初始16维实际状态完全一致。
- 三路相机顺序、全视野缩放、状态顺序、归一化处理器和夹爪编码已对齐。
- 将闭环保存的初始PNG与状态重新输入同一模型，输出与日志完全一致，最大绝对差0。
- 初始训练解码图像与闭环PNG在0–1像素尺度上的平均绝对差分别为0.00884、0.01052、0.00889。图像并非完全相同，但当前证据不足以把图像差异认定为主要原因。
- 关节重排、阈值转换、非法输入拒绝和传输容量测试通过；完整物理推进、帧应答、视频与状态记录检查通过。

这些检查降低了常见接口错误的可能性，不是对所有实现错误的绝对排除。400个目标分量触发URDF限位裁剪，说明预测有效性也需继续监测。

## episode少造成什么问题

一条成功示范只覆盖一条很窄的状态轨迹，缺少“稍偏一点如何修正”“抓空后如何恢复”等样本。它适合先做固定工况拟合，不能证明泛化。

因此应区分两个问题：

1. 当前模型能否精确拟合已有示范并完成相同初态？本次尚未通过。
2. 不同位置、角度与执行偏差下能否完成？后续需要有变化的多episode与恢复示范。

机械复制同一个确定性episode主要改变采样重复频率，不增加状态覆盖；不能代替有差异的示范。

## 下一步实验顺序

1. 保持现有数据、网络、动作编码和评价标准，增加优化更新次数，按阶段保存并评价。可先以2000、5000次为实验检查点，具体停止点由误差和闭环表现决定，不保证达到某个步数就成功。
2. 按保持初态、接近、下降、闭合、翻折、释放分别检查第一步关节误差与夹爪时机；不能只看整个动作块的平均L1下降。
3. 用固定无专家闭环逐阶段验收：是否到达抓取位、是否闭合、是否实际抓住、是否翻折释放。
4. 若训练误差足够低而闭环仍停滞，再针对动作块实际执行长度、时序融合、近似相同观测下的阶段歧义进行对照实验。当前n_action_steps=1合法，但尚未证明是本次失败的主因。
5. 固定工况取得可重复成功后，增加有小幅初态变化的成功示范和偏差恢复示范，按完整episode划分训练与验证。

优先解决拟合和闭环推进，再扩展数据覆盖。现阶段没有证据表明需要改用更大的网络、pi0.5或更大显存；渲染较慢主要影响墙钟时间，物理仍按固定步长推进。

关于模仿学习误差会随执行积累、ACT通过学习动作序列缓解这类问题，可参考原始论文：[Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware](https://arxiv.org/abs/2304.13705)。具体到本工程的失败归因以上述本地数据为依据，尚未进行训练步数或episode数量的对照实验。
