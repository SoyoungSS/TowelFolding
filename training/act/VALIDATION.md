## 结论

通过：独立环境、官方数据读取、标准ACT短程训练、模型和处理器保存重载，以及独立进程无答案推理。未接入Newton策略闭环，不报告任务成功率。

## 实际环境

- 独立venv：`.runtime/act-env311`，Python 3.11.18，不包含系统或Isaac的site-packages。
- LeRobot 0.4.4、PyTorch 2.7.0+cu128、Torchvision 0.22.0+cu128。
- Datasets 4.1.1、PyArrow 21.0.0、NumPy 2.2.6、PyAV 15.1.0。
- 实际GPU：RTX 5060 Laptop，设备报告总显存约7.525 GiB。此前文档中的其他GPU描述不作为本次依据。
- `pip check`通过。固定主依赖与完整版本快照分别在 `environments/act-requirements.txt` 和 `environments/act-tested-freeze.txt`。

选择0.4.4是为了固定可复现的v3数据和ACT接口，并非声称使用最新版本。安装中Python 3.12 PyTorch大文件下载超时，最终采用兼容0.4.4的独立Python 3.11环境，复用本机CUDA wheel；没有修改两个仿真环境。

## 数据验收

原始数据：`outputs/collect/20261109_152842_33675/dataset`。

创建训练副本后，仅修正 `meta/tasks.parquet` 的任务文本索引，以满足官方读取器返回任务字符串的约定。原始10个文件的SHA-256在训练前后均保持一致。

官方 `LeRobotDataset` 验证：

- 1条episode、815帧、30Hz。
- 3路RGB各 `[3,240,320]`，使用完整视野Resize，未中心裁剪。
- 状态 `[16]`、动作块 `[30,16]`。
- 第0、100帧各30步有效；第813帧2步有效；第814帧1步有效。
- 当前标签与原始动作行一致，填充掩码正确，任务文本正确。
- 后端显式使用PyAV，避免TorchCodec对额外FFmpeg共享库的依赖。Torchvision 0.22会发出视频API弃用提示，本固定环境已实际解码通过。

## 标准ACT训练

执行：

```bash
./run_act_stage1.sh --steps 200 --batch-size 2
```

网络为官方ACTPolicy，参数量 **51,581,840**。ResNet-18预训练，512维、8头、4层观测编码器、1层解码器、4层VAE编码器、32维潜变量，KL权重10。没有使用教学模型权重。

训练集是整条episode，通过随机DataLoader采样；每200次更新、batch 2合计约400个样本抽取，不代表完整数据已训练充分或已经收敛。

固定8个训练片段的z=0归一化动作L1：

| 更新次数 | L1 |
|---:|---:|
| 0 | 1.019722 |
| 25 | 0.569182 |
| 50 | 0.484572 |
| 100 | 0.388690 |
| 150 | 0.290822 |
| 200 | 0.255244 |

精确值以输出中的 `train_metrics.jsonl` 为准。上述片段不是独立验证集，不用于宣称泛化。

训练及保存重载验收约19.7秒，不含环境安装、数据准备与模型初始化。PyTorch记录的峰值已分配显存约1.047 GiB，不等于整个GPU或驱动的总显存占用。

## 保存重载与独立进程

- 归一化预测块 `[1,30,16]`，反归一化块形状一致，单步动作 `[1,16]`。
- 官方模型与处理器保存重载，最大预测差异为0。
- 清空队列后，`select_action`第一步与预测块第一步一致。
- 单独进程加载模型，第0帧反归一化第一步与训练进程保存的预测最大差异为0；第100帧也独立推理通过。
- 推理不传入专家动作，也不调用VAE编码器；没有发送动作到仿真或真机。
