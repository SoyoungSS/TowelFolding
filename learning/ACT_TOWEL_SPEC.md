# 双臂叠毛巾 ACT 规格与验收表

核对日期为 2026-11-12。模型结构以自主运行结果最好的 `rollout_correction_z0` checkpoint 为准，并列出多 episode 链路测试 `batch_act_smoke`。真机部署、随机化扩展与成功率目标是后续方案。

## 输入、输出与执行器

| 项目 | 当前工程 |
| --- | --- |
| 输入 | 单时刻头部、左腕、右腕三路 RGB，每路由 640×480 缩放至 3×240×320，另有 16 维实际关节与夹爪状态 |
| 输出 | 每次预测 30×16，批量形状为 B×30×16。每步依次为左臂 7 个目标关节角、左夹爪闭合值、右臂 7 个目标关节角、右夹爪闭合值 |
| 动作类型 | 14 个绝对位置目标，单位为 rad。夹爪两维训练时按连续数值回归，部署反归一化后以 ≥0.5 为闭合指令。标签 0 表示开，1 表示闭 |
| 执行器通道 | 仿真双臂各 7 个关节执行通道，各 1 个夹爪通道，共 16 个逻辑通道。真实电机数量由机械结构决定 |
| 控制节拍 | 动作 30 Hz，Newton 物理 60 Hz。执行完整 30 步相当于 1 秒仿真时间。checkpoint 默认执行 1 步，最佳闭环通过 `--action-steps 30` 覆盖 |
| 仿真执行能力 | 关节按 URDF 限位裁剪，臂关节限速 0.45 rad/s，夹爪驱动关节 0.8 rad/s。仿真归一化开度目标为开 0.5、闭 0.04。抓取还需要实际开度 ≤0.055、连续发出闭合指令至少 1 秒、布料点进入局部抓取框 |
| 接触模型 | 当前是运动学位置执行与局部粒子辅助绑定。它没有验证真实夹爪的抓力、摩擦、防滑能力或关节力矩 |

对应 [动作转换和验收](../simulation/act_io.py)、[场景参数](../simulation/scene.yaml)、[物理执行和抓取条件](../simulation/newton_env.py)。

## 模型结构和参数量

| 项目 | 实际配置 |
| --- | --- |
| 类别 | LeRobot 0.4.4 的 ACTPolicy，基于 Transformer 的模仿学习动作块策略。默认训练使用 CVAE |
| 参数和权重 | 51,581,840 个参数，约 5158 万。已保存模型权重文件约 206.5 MB，约 197 MiB |
| 视觉主干 | ImageNet 预训练 ResNet-18，三路相机共享一个视觉骨干 |
| 观测编码器 | 4 层 Transformer encoder，融合图像特征、关节状态和潜变量 |
| 动作解码器 | 1 层 Transformer decoder，30 个动作查询，对应 30 个时间位置 |
| CVAE 编码器 | 4 层 Transformer encoder，潜变量 32 维，部署时使用 z=0 |
| 层内宽度 | 模型隐藏维度 512，8 个注意力头，每头 64 维。前馈层为 512→3200→512，使用 ReLU。配置 dropout 为 0.1 |
| 输出头 | 共享线性层 512→16，共 8,208 个参数，分别作用在 30 个解码位置上 |

这里用 512 和 3200 描述层的宽度。30×16 是输出元素数。Transformer 的层数按模块列出，ResNet-18 的命名层数和 Transformer block 数采用各自的统计口径。参数总数包含训练用的 CVAE 编码器，部署时该编码器不参与前向计算。算法背景见 [ACT 原论文](https://arxiv.org/abs/2304.13705)。

## 数据来源与清单

示范由 Newton 场景的逆运动学专家生成。Isaac 同步渲染三路 RGB。每条记录包含执行前的观察和随后执行的目标，按 LeRobot v3 目录保存。Parquet 包含 `observation.state`、`action`、`timestamp`、`frame_index`、`episode_index`、`index`、`task_index`。视频为三路 MP4，`meta/` 保存字段、episode、任务和统计量。参考实采目录用于对照格式，这两个训练记录中的监督样本均来自本项目仿真。

| 数据或训练记录 | 数量与用途 |
| --- | --- |
| `outputs/collect/20261109_152842_33675/dataset` | 815 帧标准工况成功示范。最佳模型最后一轮从第 31 帧开始取样，使用 784 个窗口起点 |
| `outputs/collect/rollout_correction_frame20/dataset` | 558 帧。专家从 ACT 真实偏离处接管并完成抓取、翻折和释放 |
| `rollout_correction_z0` 的最后一轮 | 上面两条共 1,342 个训练窗口起点，约 44.7 秒对应的控制记录。两组各占一半采样概率。初始化权重经过之前的训练 |
| `outputs/collect/batch_act_smoke/batch.json` | 新尝试两轮。标准位置 815 帧，通过，平均误差 12.0 mm。偏移轮误差 33.4 mm，未纳入训练 |
| `batch_act_smoke` 短训 | 新标准位置成功示范和历史标准位置示范，共 2 条、1,630 帧。实际参与这次短训的两条都在标准位置 |
| `outputs/collect/regrasp_cuda_frame273` | 868 帧重新夹取诊断数据。采集时达标，四次独立动作回放均未达标，未用于上述两轮训练 |

30 步监督目标从各 episode 内生成，末尾缺失动作使用掩码。相邻窗口大量重叠，因此 1,342 个窗口起点仍只有 2 条独立轨迹。建议用 20–50 条通过验收的不同示范作为下一轮工程预算，包含完整折叠和针对真实失误的纠偏，并按 episode 与初态分出留出集。数量是实验预算，由闭环结果决定是否继续加数据。

## 训练目标、随机化与真机路线

- **标准模仿损失**为带动作填充掩码的归一化动作 L1，加上权重为 10 的 CVAE KL 项。优化器 AdamW，学习率 1e-5。当前最佳模型的最后一轮采用 `--finetune-z0`，在有效位置上分别求 14 维手臂和 2 维夹爪的平均 L1，再相加。两个夹爪维度因此有独立的损失权重。折后几何只用于筛选与验收，训练没有使用强化学习奖励。
- **已实现随机化**是批量采集中的毛巾 XY 初始平移。首轮为标准位置，后续按种子采样，默认每轴 ±3 mm。当前训练与部署日志没有记录相机、关节传感器、动作延迟或驱动噪声注入，也没有验证旋转、光照、摩擦和材质随机化后的泛化。
- **建议的 Sim2Real 顺序**是先对齐相机视角、时间戳、关节零位与符号和夹爪开合映射。测量真机的位置跟踪、延迟、夹爪开度和布料滑移，再把测到的变化范围用于视觉与动力学随机化。然后收集同一相机布局和动作定义的真机示范，微调并用留出的真机工况验收。视觉与动力学随机化的参考分别见 [Tobin 等](https://arxiv.org/abs/1703.06907) 和 [Peng 等](https://arxiv.org/abs/1710.06537)。这些研究提供方法参考，当前毛巾任务的迁移效果仍需实测。

## 设备、耗时与成功率

| 项目 | 实测或建议 |
| --- | --- |
| 训练设备 | RTX 5060 Laptop GPU，标称 8 GB，训练日志识别约 7.53 GiB。PyTorch 2.7 CUDA 12.8，batch size 2，未开 AMP。最佳模型最后一轮 PyTorch 峰值分配约 0.81 GiB。该数值不含驱动、渲染等其他占用，最低配置尚未测定 |
| 部署设备 | 真机需同步三路 RGB、双臂关节位置反馈、夹爪状态和位置命令接口。当前仿真策略进程要求 CUDA，可先用已有 GPU 测端到端时延。真机还需要独立的低层位置控制、关节限位和限速、超时停止与急停 |
| 控制时延预算 | 30 Hz 每条命令间隔约 33.3 ms。最佳闭环在 30 步队列模式下，策略请求日志均值约 11.0 ms、P95 约 12.7 ms。统计混合了重算和队列取动作，不能代替单次重算或真机端到端时延测试 |
| 采集耗时 | 批量两次尝试约 199–257 秒墙钟时间/轮。标准示范约 27.2 秒仿真时间。实际采集工期还取决于通过率 |
| 训练耗时 | 最佳模型最后一轮 2,400 步约 166 秒。批量链路短训 25 步约 3.2 秒。训练计时含训练末尾保存和重载等操作，启动和准备数据另外计时 |
| 仿真耗时 | 最佳闭环 29 秒仿真时间，程序记录约 230 秒墙钟时间。批量短训模型同长度闭环约 252 秒 |
| 单轮通过条件 | 两侧曾实际抓持，结束时释放，平均镜像点对水平距离 <25 mm，最大距离 <50 mm，折后 X 向宽度比 <68% |
| 当前结果 | 最佳 ACT 独立完成抓取、翻折与释放，平均 51.0 mm、最大 77.7 mm、宽度比 60.8%，该轮未达标。批量 25 步短训模型未抓住。独立初态的成功率尚未测量 |
| 建议阶段目标 | 标准初态先争取 10 次中至少 9 次达标，再在 20 次预先定义的留出初态中至少 18 次达标，分别报告成功次数、边缘误差和耗时。这些是建议验收门槛，不是已达到的成功率或真机承诺 |
